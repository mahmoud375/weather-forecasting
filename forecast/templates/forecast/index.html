REST API Specification
Endpoint
POST /api/predict/
Sample Request (cURL)
curl -X POST http://127.0.0.1:8000/api/predict/ \
  -H "Content-Type: application/json" \
  -d '{
    "model_choice": "rf",
    "temp_max_c": 30.5,
    "temp_min_c": 19.0,
    "humidity_pct": 52.0,
    "wind_speed_max_kmh": 16.5,
    "precipitation_mm": 0.0,
    "cloud_cover_pct": 25.0
  }'
